💡 How XP works

10 XP per focused minute. Day streak multiplies it (+5% per day, up to +50%). Finish without slipping onto other apps → +20% clean bonus. Abandoning a session banks only 25%.

SHIELD

Strict mode

Tracks time you spend off the app mid-session. Stay clean → +20% XP bonus. Locking your phone is fine — that's the goal.

☢️ The nuclear option

Aeroplane mode + phone face-down, or phone in another room. Start the session, lock the screen, walk away. The timer keeps counting — it works off the clock, not the screen.

⏳ App Limits (real blocking)

iPhones can hard-block apps for free — no subscription needed:

  1. Settings → Screen Time → App Limits → Add Limit
  2. Pick Instagram, TikTok, YouTube, Snapchat
  3. Set the limit to 1 minute per day
  4. When you hit it, the apps grey out until midnight
Pro move: set a Screen Time passcode and get someone else to type it so you can't "Ask For More Time".

🌘 Focus mode combo

  1. Settings → Focus → + → create one called Locked In
  2. Allow calls from family only, silence everything else
  3. Under Customise Screens, show only a home page with FLOWSTATE on it
  4. Flip it on every time you lock in

🤝 The honesty check

A web app can't see what other apps you open — only that you left. If you were gone a while, FLOWSTATE asks whether you slipped. Lie and you're only scamming your own XP.
